# TKProtect for YouTube Morphe

Патч для **YouTube Morphe**, который добавляет в плеер кнопку **TK**. Тап по кнопке открывает
панель TKProtect: она автоматически привязывается к **текущему видео** (обычное видео или
Shorts), читает его live-чат и комментарии и проверяет их через TKCore. ID видео вводить не нужно.

**Сервер не нужен.** Вся логика (проверка TKCore, чтение YouTube, интерфейс) работает внутри
приложения.

## Режимы

- **Зритель (по умолчанию):** только **локальное скрытие** спама/скама в панели TKProtect. Нужен
  только TKCore API key. Google Cloud, OAuth и токены **не требуются**, сообщения на YouTube не
  удаляются.
- **Стример (опционально):** дополнительно **авто-удаляет** нарушающие сообщения из live-чата
  через YouTube Data API от имени канала. Требуется собственная Google-авторизация стримера
  (OAuth device code flow) и хранение токенов **только на устройстве**. Для зрителей этот режим
  не нужен.

## Возможности

- кнопка **TK** в оверлее плеера YouTube Morphe;
- тап → панель внутри приложения, долгий тап → настройки;
- **автоматическое определение videoId** (`AddOnApi.addVideoIdListener`) — работает для зрителя и
  стримера; при смене видео панель переключается сама;
- если у видео нет живого чата, панель сама открывает вкладку комментариев;
- чтение live-чата и комментариев через внутренний API YouTube (Innertube);
- проверка текста через TKCore (`easyapi.php?type=botmoderator`) с кэшированием и авто-подбором
  версии API (1.0/2.0);
- локальное скрытие, чекбокс «Показывать скрытые», счётчики, журнал, ручная проверка;
- автообновление раз в 5 секунд;
- при ошибке проверки сообщение **не скрывается** (fail-open);
- (стример) авто-удаление нарушений из live-чата после Google-авторизации.

## 1. Сборка `.mpp`

### Через GitHub Actions (рекомендуется)

1. Нажмите **Use this template** или загрузите файлы в новый репозиторий.
2. **Actions** → **«Build TKProtect .mpp»** → **Run workflow**.
3. Дождитесь окончания, скачайте артефакт `tkprotect-mpp`, распакуйте его.
4. Внутри будет `patches-<версия>.mpp`.

### Локально

Нужны Java 21+ и интернет; задача `buildAndroid` сама подготовит Android SDK.

```powershell
.\gradlew.bat buildAndroid
```

Если `android.jar` уже есть в другом месте:

```powershell
.\gradlew.bat buildAndroid -PandroidJar="I:\path\to\android.jar"
```

> Плагин `app.morphe.patches` лежит в GitHub Packages, поэтому для локальной сборки нужен
> токен с правом `read:packages` (`gpr.user` / `gpr.key` или `GITHUB_ACTOR` / `GITHUB_TOKEN`).
> В GitHub Actions токен подставляется автоматически.

## 2. Установка

1. Скопируйте `.mpp` на телефон.
2. Morphe Manager → **Settings → Patches sources → Add source** → выберите файл.
3. При патчинге YouTube включите **«TKProtect panel»**.
4. Перепатчьте YouTube и установите APK.

Поддерживаемые версии YouTube перечислены в
`patches/src/main/kotlin/app/tkprotect/patches/youtube/YouTubeCompatibility.kt`.

## 3. Настройка

Долго нажмите кнопку **TK** в плеере.

### Режим зрителя (по умолчанию)

| Поле | Что это |
|------|---------|
| **Режим** | `Зритель (локальное скрытие)` |
| **TKCore API key** | обязательно — ваш ключ от TKCore |
| TKCore URL | адрес `easyapi.php`; по умолчанию уже заполнен |
| Режим (phrase2) | по умолчанию `0` |
| Версия API | `1.0` (рекомендуется), `2.0`, `Авто (подбор)`; при ошибке выбранной версии патч пробует другую и запоминает рабочую |
| YouTube API key (Innertube) | публичный ключ Innertube; по умолчанию уже заполнен |
| Версия клиента YouTube | по умолчанию уже заполнена |

Обычно достаточно вставить только **TKCore API key** и нажать **«Сохранить»**. Всё хранится в
SharedPreferences на устройстве и никуда не отправляется, кроме самого TKCore.

> **Важно:** ключ из `web/config.php` (старая PHP-панель) патчем **не используется**.
> Надпись «Ключ из web/config.php патчем НЕ используется» — это **предупреждение**, а не
> подтверждение сохранения. Нужно вставить тот же ключ в поле **TKCore API key** и нажать
> **«Сохранить»**.
>
> После сохранения появится зелёная надпись «Ключ сохранён: ****abcd», а вверху панели —
> `TKProtect активен · ключ ****abcd · API 1.0 · Зритель`. Если красным написано
> «КЛЮЧ НЕ СОХРАНЁН» или «TKCore ключ не сохранён (длина 0)» — ключ в настройки не попал.
>
> Кнопка **«Проверить ключ TKCore»** отправляет реальный запрос (для `Авто` — к 1.0 и 2.0) и
> показывает сырой ответ.

Дальше тапните **TK** на видео: ID подставится автоматически, скрытие начнётся сразу. Если ключа
нет, все записи получают вердикт «Ошибка проверки» и **не скрываются** (fail-open). Поле ID можно
изменить вручную кнопкой «Обновить».

### Режим стримера (модерация live-чата)

Режим стримера **дополнительно** модерирует нарушающие сообщения в live-чате через YouTube Data
API. Для него нужны собственные Google OAuth-креды стримера (каждый стример настраивает их сам). В
репозиторий/патч ничего из этого не вшивается; токены хранятся только на устройстве.

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект (или выберите
   существующий).
2. Включите **YouTube Data API v3**.
3. Настройте OAuth consent screen (для личного использования достаточно тестового режима и себя в
   Test users).
4. Создайте OAuth client ID типа **TVs and Limited Input devices** (device code flow — без сервера и
   redirect URI). Скопируйте **Client ID** (и Client Secret, если он выдан).
5. В настройках TKProtect переключите **Режим** на `Стример (авто-удаление через YouTube API)`.
6. Вставьте **Google Client ID** (и Secret при наличии), нажмите **«Войти через Google (код)»**,
   откройте показанную ссылку, введите код и подтвердите доступ.
7. Привяжите стрим: **«Найти мой активный стрим»** (эфир должен быть запущен и принадлежать
   авторизованному аккаунту) или включите ручную привязку и укажите `liveChatId`.
8. Нажмите **«Сохранить»**.

**Настройки действий стримера (по умолчанию безопасные):**

- **Действие при нарушении:** `Авто-удалять` (по умолчанию) или `Только помечать (ручное
  подтверждение)`. В ручном режиме в панели у нарушающего сообщения появляется кнопка действия.
- **Бан/таймаут нарушителей:** `Выкл` (по умолчанию), `Таймаут` (с настраиваемой длительностью,
  сек) или `Бан навсегда`. Из-за возможных ложных срабатываний по умолчанию выключено.
- **Привязка стрима:** `Авто-поиск активного стрима` (по умолчанию) или `Вручную (liveChatId)`
  — по умолчанию выключено.

После настройки нарушения, отмеченные TKCore, будут обработаны согласно выбранным действиям (в
панели отображается отметка об удалении/бане/ошибке). Для выхода используйте **«Выйти из Google
(удалить токены)»**.

> **Ограничения стримерского режима:** модерация через API сейчас применяется к **live-чату**.
> Комментарии под видео по-прежнему скрываются только локально в панели. Требуются права/квота
> YouTube Data API у аккаунта стримера; возможность удаления/бана зависит от прав канала и
> соответствия ID сообщений (чат читается через Innertube, действия — через Data API).

## Если ключ «не сохраняется» или ничего не скрывается

- **«Проверить ключ TKCore»** проверяет введённый ключ, но **не сохраняет** его. Обязательно нажмите
  **«Сохранить»**. Признак сохранения — зелёная надпись «Ключ сохранён: ****abcd» в настройках и
  статус в панели с маской ключа.
- Если панель была открыта до сохранения, статус мог остаться старым; теперь он обновляется при
  опросе, но можно закрыть/открыть панель или нажать «Обновить».
- Ошибочные ответы TKCore (например, неподходящая версия API) больше не кэшируются как «безопасные»,
  поэтому после исправления ключа/версии повторная проверка сработает.
- Скрываются только типы нарушений (`obscene`, `phishing`, `caps_flood`, `pii`, `scam`,
  `blacklist`). Обычные сообщения (`allowed`, `scanner`/ссылки, whitelist) скрываться не будут.
- Скрытие отображается **в панели TKProtect**, а не в родном UI комментариев YouTube.

## Необязательно: веб-версия

Папка `web/` содержит прежнюю PHP-панель. Она **не нужна для работы патча** — оставлена на
случай, если хочется открыть панель на компьютере в браузере. Для неё нужен PHP-сервер:

1. скопируйте `web/` в каталог сайта (например, `home/youtube-morphe/`);
2. скопируйте `config.local.php.example` → `config.local.php` и вставьте свой ключ;
3. откройте `index.php?v=VIDEO_ID`.

Можно смело удалить папку `web/` из репозитория — на патч это никак не повлияет.

## Если чат перестал читаться

Внутренний API YouTube неофициальный. Обновите «YouTube API key» и «Версию клиента YouTube»
в настройках патча. Актуальные значения берутся из HTML любого видео YouTube
(`INNERTUBE_API_KEY` и `INNERTUBE_CLIENT_VERSION`).
