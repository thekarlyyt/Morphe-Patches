# Morphe YouTube · TKProtect

Самодостаточный PHP+JS-модуль: вкладка TKProtect, чтение live-чата и комментариев
YouTube и **локальное скрытие** нарушающих сообщений через TKCore.

**Регистрация приложения в Google Cloud не требуется.** Модуль читает публичные чат
и комментарии через внутренний API YouTube (тот, что используют сами веб-клиенты),
поэтому не нужны OAuth-клиент, client ID/secret, токены и оплата. Удаление на YouTube
не выполняется — сообщения скрываются только в браузере.

## Что умеет

- Читать live-чат трансляции и комментарии под видео через внутренний API YouTube.
- Проверять текст через TKCore (`easyapi.php?type=botmoderator`, как в
  `superbotmoderator.php`) с кэшированием вердиктов в сессии.
- Скрывать нарушающие сообщения/комментарии **локально** в браузере.
- Чекбокс «Показывать скрытые сообщения» — чтобы посмотреть, что именно скрыто.
- Статистика, журнал действий, ручная проверка текста, автообновление раз в 5 секунд.
- Подключение по ID видео (`index.php?v=VIDEO_ID`).

## Установка

1. Поместите папку модуля на PHP-сервер (PHP 7.4+, расширения **curl**, **json**, **mbstring**).
2. Скопируйте `config.php` в `config.local.php` и заполните `tk_api_key` — ваш ключ
   TKCore API. Остальные параметры можно оставить по умолчанию.
3. Откройте `index.php`, введите 11-символьный ID видео/трансляции → «Подключиться».

### Настройка

| Параметр | Назначение |
|----------|------------|
| `tk_api_base` | адрес `easyapi.php` плагина TKCore |
| `tk_api_key` | ваш TKCore API key (обязательно) |
| `tk_mode` / `tk_version` | параметры проверки фраз, как в `superbotmoderator.php` |
| `yt_innertube_key` | публичный ключ внутреннего API YouTube; если перестанет работать — замените на актуальный из веб-клиента YouTube |
| `yt_client_version` | версия веб-клиента YouTube; также может требоваться обновления |
| `check_limit_per_poll` | сколько новых текстов проверять за один опрос |

> Внутренний API YouTube не является официальным публичным интерфейсом. Если YouTube
> изменит ключ или формат ответа, обновите `yt_innertube_key` / `yt_client_version`
> в `config.local.php`. Официальный путь потребовал бы регистрации приложения в Google.

## Структура

| Файл | Назначение |
|------|------------|
| `index.php` | UI: вкладки «Чат стрима», «Комментарии», «TKProtect» |
| `api.php` | JSON-endpoints: bootstrap, check, chat, comments |
| `lib.php` | HTTP, TKCore, внутренний YouTube API, извлечение чата/комментариев, CSRF |
| `config.php` / `config.local.php` | Конфигурация |
| `assets/app.js`, `assets/styles.css` | Фронтенд |

## Замечания

- Скрытие действует только в том браузере, где открыта страница. На YouTube сообщение
  остаётся видимым для всех остальных зрителей.
- При ошибке проверки TKCore (`type=error`) сообщение **не скрывается** — модуль работает
  по принципу fail-open.
- Кэш вердиктов хранится в сессии (`verdict_ttl` секунд), чтобы не дёргать TKCore
  повторно для одного и того же текста.
